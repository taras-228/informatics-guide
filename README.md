Тема

Системы счисления



Цель

Изучить основные системы счисления

и способы перевода чисел.



Автор

Студент первого курса



Содержание

README.md — описание проекта

glossary.md — словарь терминов

examples.md — примеры решения задач

sources.md — использованные источники

questions.md — вопросы для самопроверки



Описание

Справочник предназначен для студентов

первого курса, изучающих информатику.



Как пользоваться справочником

Для изучения материала рекомендуется следующий порядок:



Прочитать README.md и ознакомиться с целью проекта.

Изучить основные термины в glossary.md.

Разобрать примеры в examples.md.

Изучить источники в sources.md.

Ответить на вопросы в questions.md.



Рекомендуется самостоятельно выполнять примеры,

чтобы лучше освоить тему.
